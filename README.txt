今天也要活著｜第三版（快取修正版）

本版沿用第二版介面、日曆、收藏、隨機換句功能。
更新 sw.js：新版本啟用後自動清理 daily-quote-v1/v2 等舊快取；連線時優先取得最新檔案，離線時使用快取。

更新 GitHub：
1. 解壓縮 ZIP。
2. 到 daily-quotes-app 專案首頁 → Add file → Upload files。
3. 選取解壓縮後的六個檔案（不是資料夾），Commit changes。
4. 等 GitHub Pages 部署完成，關閉舊分頁再重新開啟網站。第一次更新時若仍看到舊版，請重新整理一次。

注意：收藏存於瀏覽器 localStorage，清除網站資料可能導致收藏遺失。
目前每個模式只有 5 句，尚未補齊 730 句。
