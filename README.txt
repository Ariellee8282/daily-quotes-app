今天也要活著｜每日語錄 PWA
1. 將整個資料夾的檔案上傳到 GitHub 公開 repository 的根目錄。
2. GitHub repository → Settings → Pages → Deploy from a branch → main / root → Save。
3. 等待 GitHub Pages 網址啟用，用 iPhone Safari 開啟 → 分享 → 加入主畫面。
4. 要增加語錄：修改 quotes.js，新增 {mode:'sarcastic',text:'...'} 或 {mode:'healing',text:'...'}。
5. 若在 Google Sheets 編輯資料，需另行匯出並轉換成 quotes.js；目前不是自動同步。
注意：此版提供每日依日期輪替、手動換一句、模式切換、收藏與文字分享。日曆頁面只是後續擴充說明，尚無完整月曆；無推播、無帳號同步。收藏只保存在本機瀏覽器，清除網站資料會遺失。
